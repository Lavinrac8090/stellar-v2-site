隱私權政策

適用於 StellarV2 Backups。更新日期：2026 年 10 月 18 日。

範圍與維護者

本工具由 GitHub 使用者 Lavinrac8090 維護，供其個人研究備份使用。公開網站只提供說明，沒有登入表單、廣告或分析追蹤程式。網站託管服務可能依其自身政策處理 IP 位址及請求紀錄。

存取與用途

在使用者同意後，本工具透過 Google OAuth 的 drive.file 範圍建立備份資料夾、查詢其備份檔案的識別碼與中繼資料、上傳備份，並下載檔案以核對完整性及測試恢復。它只能存取應用程式建立或使用者明確授權的檔案，不要求全 Drive 存取。

備份可包含公開市場資料、研究狀態、報告、事件帳本及程式版本。Google 檔案資料僅用於備份與恢復，不用於廣告、出售或訓練通用 AI 模型。

儲存、處理與分享

OAuth 憑證儲存在擁有者私有 GitHub 專案的 Actions Secrets。備份工作由 GitHub-hosted runner 處理，備份保存在擁有者的 Google Drive。檔案識別碼、雜湊與驗證結果可能記錄在私有執行紀錄中。Google 與 GitHub 各自處理提供服務所需的資料。

程式不會將 OAuth 憑證放入備份或公開網站，也不會自動公開 Drive 檔案。具備相應 GitHub 專案或 Google 帳號權限的人員，可能依其權限存取相關資料或操作工作。

保留、撤銷與刪除

目前不會自動刪除舊備份。擁有者可在 Drive 刪除備份並依需要清空垃圾桶；可在 Google 帳號的第三方連線設定撤銷授權，並刪除 GitHub 的 GOOGLE_DRIVE_CREDENTIALS Secret。撤銷授權會停止後續存取，不會自動刪除既有備份、Git 歷史或執行紀錄，這些需分別處理。

Google 使用者資料

StellarV2 Backups 使用及轉移從 Google API 取得的資訊，遵循 Google API 服務使用者資料政策，包括 Limited Use 要求。

聯絡與變更

一般問題可透過網站專案 Issues聯絡維護者。請勿在公開留言提供敏感資料。資料處理方式變更時，將更新本頁；如需新增 Google 權限，將重新請求授權。
