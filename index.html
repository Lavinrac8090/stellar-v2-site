StellarV2 Backups

為個人使用的 StellarV2 投資研究專案保存備份，讓公開市場資料、研究報告與程式版本可以恢復。

目前供擁有者本人使用。這個網站提供工具與資料處理說明，不提供登入、下單或投資建議服務。

工具如何運作

  1. Python 工作在 GitHub Actions 執行，下載公開市場資料並產生研究報告。
  2. 取得擁有者同意後，將備份包寫入其 Google Drive 的 StellarV2_Backups 資料夾。
  3. 重新下載備份，比對 SHA256，並測試檔案恢復。

Google Drive 授權

僅請求 drive.file 權限，用於存取這個應用程式建立或使用者明確授權給它的檔案。工具不要求讀取整個 Drive。
